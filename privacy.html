PRIVACY POLICY

隱私權政策プライバシーポリシー

制定日期：2026 年 10 月 24 日制定日：2026年10月24日

「開拓者の愉悅部」（以下稱「本站」，網址 https://ccc15921.github.io/twkaitakusha/）是由 AZKi 粉絲（開拓者）個人製作的非官方粉絲網站，與 COVER 株式会社及 hololive production 無關。本政策說明本站如何收集、使用與保護你的資料。

1. 不登入也能使用

本站所有收藏紀錄功能都可以在不登入的情況下使用。未登入時，你的紀錄只會儲存在你自己瀏覽器的 localStorage 中，不會傳送到任何伺服器。語言與深色模式設定也同樣只存在你的瀏覽器裡。

2. 使用 Google 帳號登入時收集的資料

你可以選擇用 Google 帳號登入，以便在不同裝置之間同步紀錄。登入時，本站會透過 Google 取得並儲存：

  • 你的 Google 帳號電子郵件地址
  • Google 提供的帳號識別碼
  • Google 帳號的名稱與頭像網址（僅用於登入後在你自己的畫面上顯示，不會公開）

本站只要求基本的登入權限（email、profile、openid），不會存取你的 Google 雲端硬碟、Gmail、聯絡人或其他 Google 服務的資料。

3. 你在本站產生的資料

  • 周邊繳稅紀錄與 Voice 收集紀錄（項目代號、數量、更新時間）
  • 你自行設定的暱稱與自行上傳的頭像圖片（上傳前會在瀏覽器內縮小並移除照片中的位置等資訊）
  • 你的設定，例如是否參加排行榜、是否計入購買人數統計
  • 你送出的檢舉內容（被檢舉的對象與原因）

4. 資料的使用目的

  • 在你的各個裝置之間同步紀錄
  • 以匿名方式統計每件周邊／Voice 的購買人數與熱門排行（只顯示人數，不顯示是誰）
  • 在你自願參加時，於排行榜顯示你的暱稱、頭像、完成率或繳稅金額
  • 處理檢舉並維護網站秩序

本站不會將你的資料用於廣告，不會出售，也不會提供給第三方，法律要求的情況除外。

5. 會公開的內容

  • 購買人數統計：只公開每件項目的總人數。你可以在個人設定中選擇不計入統計。
  • 完成率排行榜：僅在你主動開啟參加時，公開你的暱稱、頭像與完成率。
  • 金額排行榜：僅在你另外勾選加入時，公開你的暱稱、頭像與繳稅金額。

你的 Google 電子郵件、Google 名稱與 Google 頭像不會公開顯示。

6. 資料的儲存

登入後的資料儲存在本站使用的雲端資料庫服務 Supabase 上，並設定為每個人只能讀寫自己的紀錄。網站本身由 GitHub Pages 提供。這些服務可能位於台灣以外的地區。

7. 刪除你的資料

你可以隨時登出，登出後紀錄仍保留在該裝置的瀏覽器中。若要刪除雲端上的所有資料，可使用網站上的刪除帳號功能，或透過下方聯絡方式提出，我們會在合理期間內刪除。清除瀏覽器的網站資料即可刪除儲存在你裝置上的紀錄。

8. Google 使用者資料

本站對於從 Google API 取得之資料的使用與轉移，遵守 Google API 服務使用者資料政策，包括其中的「有限使用」規定。

9. 政策變更

本政策若有變更，會更新於本頁並修改上方的日期。重大變更時會在網站上公告。

10. 聯絡方式

對本政策或你的資料有任何疑問，請透過 GitHub Issues 與我們聯絡。

1. ログインなしでも利用できます

本サイトの記録機能はすべてログインなしで利用できます。ログインしていない場合、記録はお使いのブラウザの localStorage にのみ保存され、サーバーには送信されません。言語やダークモードの設定も同様です。

2. Google アカウントでログインした場合に取得する情報

複数の端末で記録を同期するため、Google アカウントでログインすることができます。ログイン時、Google を通じて以下の情報を取得・保存します。

  • Google アカウントのメールアドレス
  • Google が提供するアカウント識別子
  • Google アカウントの名前とプロフィール画像の URL（ログイン後のご自身の画面表示にのみ使用し、公開しません）

本サイトが要求するのは基本的なログイン権限（email・profile・openid）のみで、Google ドライブ、Gmail、連絡先などのデータにはアクセスしません。

3. 本サイトで作成される情報

  • グッズの納税記録とボイスの収集記録（項目コード、数量、更新日時）
  • ご自身で設定したニックネームとアップロードしたアイコン画像（アップロード前にブラウザ内で縮小し、位置情報などを削除します）
  • ランキングへの参加や購入人数統計への算入などの設定
  • 送信された通報内容（通報対象と理由）

4. 利用目的

  • 端末間での記録の同期
  • 各グッズ・ボイスの購入人数と人気ランキングの匿名集計（人数のみ表示し、誰が購入したかは表示しません）
  • ご自身で参加を選んだ場合のランキングへのニックネーム・アイコン・コンプリート率・納税額の表示
  • 通報への対応とサイトの健全な運営

取得した情報を広告に利用したり、販売したり、第三者に提供したりすることはありません（法令に基づく場合を除く）。

5. 公開される内容

  • 購入人数統計：各項目の合計人数のみ公開します。個人設定で統計に含めないこともできます。
  • コンプリート率ランキング：ご自身で参加をオンにした場合のみ、ニックネーム・アイコン・コンプリート率を公開します。
  • 納税額ランキング：別途参加にチェックした場合のみ、ニックネーム・アイコン・納税額を公開します。

Google のメールアドレス、名前、プロフィール画像が公開されることはありません。

6. 情報の保存

ログイン後のデータはクラウドデータベースサービス Supabase に保存され、各ユーザーは自分の記録のみ読み書きできるよう設定しています。サイト自体は GitHub Pages で公開しています。これらのサービスは日本・台湾以外の地域にある場合があります。

7. 情報の削除

いつでもログアウトでき、ログアウト後も記録はその端末のブラウザに残ります。クラウド上のすべてのデータを削除したい場合は、サイト上のアカウント削除機能を使うか、下記の連絡先からご依頼ください。合理的な期間内に削除します。端末に保存された記録は、ブラウザのサイトデータを消去することで削除できます。

8. Google ユーザーデータについて

本サイトによる Google API から取得した情報の使用および転送は、Google API サービスのユーザーデータに関するポリシー（「限定的使用」の要件を含む）に従います。

本ポリシーを変更する場合は、本ページを更新し上記の日付を改めます。重要な変更はサイト上でお知らせします。
